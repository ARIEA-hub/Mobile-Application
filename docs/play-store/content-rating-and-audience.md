# Content rating and target audience

## Target audience and content (App content → Target audience)

- **Age groups to select: 13–15, 16–17, 18 and over.** Do **not** select anything under 13.
- **Why:** the app is a general alarm clock. "Parent Mode" is a tool for a *parent* to configure a child's
  alarms; the app itself is not directed at children. Selecting under-13 age groups would put it under the
  Families Policy, which restricts third-party services (the optional Gemini counselor) and applies stricter
  rules than this app is designed for.
- **Appeals to children?** Answer **No**. (The mascot logo is stylised, not childlike. If Google's review
  disagrees, the fix is a Families-compliant build, not a different answer.)
- Parent Mode already turns every online feature off, so it is safe even if a child uses the app.

## Content rating questionnaire (IARC)

Category: **Utility, Productivity, Communication or Other** (not a game).

| Question | Answer |
| --- | --- |
| Violence (cartoon, realistic, blood, etc.) | None. (The "boss fight" is a set of puzzles; no depiction of violence.) |
| Sexual content or nudity | None |
| Profanity or crude humour | None |
| Controlled substances (drugs, alcohol, tobacco) | None *depicted*. The counselor gives sleep advice that mentions alcohol and caffeine; this is health information, not promotion. If the form asks about references, answer "educational/health". |
| Gambling or simulated gambling | None |
| Users can interact or exchange content with each other | **No**: there is no user-to-user feature |
| Shares user's location with others | No |
| Allows purchases of digital goods | No |
| Unrestricted internet access / web browsing | No |
| Contains AI-generated content | **Yes, optionally**: the online counselor, off by default, with a reporting link |

Expected result: **Everyone / PEGI 3 / equivalent**. A health-advice chatbot may raise it slightly; accept
whatever IARC returns.

## Health apps declaration

The sleep counselor is general wellness information. In the declaration, state that the app:

- is **not** a medical device and offers no diagnosis, treatment or clinical measurement;
- gives general sleep-hygiene information with an on-screen note that it is not medical advice;
- tells users to see a doctor for persistent problems, and answers messages about self-harm with a caring
  reply that points to emergency help.
